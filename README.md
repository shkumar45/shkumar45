### 🏔️ Earlier Work

I previously worked on [Everest](https://github.com/shkumar45?tab=repositories&q=everest), a simple employee management system built to explore microservices and distributed systems concepts using **Java, Spring Boot, and React**.

Everest includes:

- Employee and Department microservices built with Java and Spring Boot
- Resiliency using Resilience4j — circuit breakers, retries, fallbacks, etc.
- Service-to-service communication between Employee and Department microservices
- Service discovery using Eureka
- Distributed tracing using Zipkin and Sleuth
- Centralized configuration using GitHub
- React frontend for consuming the backend services
- Kubernetes deployment for the entire application stack

My goal is to eventually make Everest production-ready with proper **CI/CD, observability, and Kubernetes deployment**.
